# R_population_data_analysis
🚀 Global Population Trends: End-to-End Data Analysis in R 📊🌍I recently completed an end-to-end data analysis project in R exploring global demographics and historical population growth from 1970 to 2022.Here is a breakdown of the workflow and key data engineering steps involved:1. Data Ingestion & Exploratory AnalysisLoaded the global population dataset using readr and evaluated structure, variable data types, and key statistics using str() and summary().  2. Data Transformation & AggregationFiltered, selected, and arranged key spatial attributes (Country, Capital, Continent, Growth Rate) using dplyr and pipe operators (%>%).  Computed continent-level aggregations and mean populations to evaluate demographic distributions.  3. Data Cleaning & Missing Value ImputationEvaluated missing values across columns using colSums(is.na()).  Applied automated column-wise imputation (mutate + across) replacing missing numeric values with column means, and dropped invalid rows using drop_na().  Deduplicated records using distinct() to ensure high data integrity.  4. Reshaping & Encoding FixesStandardized text encodings (iconv UTF-8 conversion) to ensure smooth cross-platform rendering.  Reshaped wide population columns into a clean long format using tidyr::pivot_longer(), extracting historical years (1970–2022) with regex string operations (gsub) for time-series evaluation.  5. Data Visualization (ggplot2 & treemapify)Bar Charts: Highlighted average population sizes across continents and rendered a horizontal bar chart of the top 10 most populous countries.  Time-Series Line Chart: Tracked total population trajectories per continent across multi-decade spans (1970–2022).  Treemap: Visualized global population percentage shares distributed by country and continent using treemapify.  🛠 Tools & Packages Used: R, tidyverse, dplyr, tidyr, ggplot2, treemapify, readr  #DataAnalysis #RStats #DataVisualization #Tidyverse #DataScience #DataCleaning #ggplot2
